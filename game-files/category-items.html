Снаряжение

Тип: Инвентарные и тяжёлые предметы

Предметы (ориг. Outlast Trials Items) — снаряжение в игре The Outlast Trials, используемое протагонистами на испытаниях.

Содержание

Описание

Различные предметы на испытаниях, с которыми реагентам приходится взаимодействовать. Некоторые предметы служат просто для упрощения прохождения испытаний, такие как кирпичи или антидот. Однако на некоторых испытаниях есть необходимые предметы для прохождения, такие как дешифратор или микроволновый пульт. Помимо предметов, которые реагент кладёт к себе в инвентарь, существуют также тяжёлые предметы, которые необходимо держать двумя руками. Данные предметы не кладутся в инвентарь, и им свойственно вываливаться из рук при каких-нибудь обстоятельствах.

Побочное задание

  • Плакаты — второстепенные предметы, развешанные в случайных местах на каждом испытании. За их сбор реагент получает дополнительную награду. Для одного игрока достаточно собрать 3 плаката, но если же игроков более одного, то 5.
  • Подарки — альтернатива плакатам во время действия временной программы «Зима приносит смерть». За их сбор реагент получает +2 жетона событий. Для одного игрока достаточно собрать 5 подарков, но если же игроков более одного, то 10.
  • Крысы — альтернатива плакатам во время действия временной программы «Токсический шок». За их сбор реагент получает +1 жетон событий. Для одного игрока достаточно собрать 5 крыс, но если же игроков более одного, то 10.
  • Схемы — альтернатива плакатам во время действия временной программы «Под наблюдением». За их сбор реагент получает +3 жетона событий. Для одного или более игроков достаточно собрать 3 схемы.

Предметы испытаний

  • Кирпич — небольшой кирпич, предназначенный для кратковременного оглушения врагов. Также кирпичом можно обезвредить различные вражеские ловушки. Кирпич можно кинуть во врага 2 раза, и после чего он полностью сломается. С надетой амфой «Сильная рука» кирпич немного сильнее оглушает врагов, но ломается с первого броска. С надетой амфой «Поломатор» бросок кирпича в закрытый контейнер открывает его.
  • Бутылка — одноразовая пустая бутылка, предназначенная для слабого кратковременного оглушения врагов или отвлекающего манёвра, кинув её в сторону. Также бутылкой можно обезвредить различные вражеские ловушки. Существует 4 вида бутылок, а именно из-под пива, двух газировок и острого соуса.
  • Антидот — хлорпромазин, предназначенный для мгновенного лечения от психоза или просто восстановления неполного рассудка.
  • Адреналин — бензедрин, предназначенный для временного повышения выносливости, который даёт неограниченный бег, прыжки и удары.
  • Отмычка — маленький предмет, предназначенный для отпирания запертых на электронный замок контейнеров и дверей. С надетой амфой «Мастер-взломщик» одну отмычку можно использовать дважды.
  • Слабое лекарство — маленькая бутылка с лекарством, предназначенная для лечения одного деления здоровья. С надетой амфой «Вторичное использование» после лечения тару из-под лекарства можно использовать, как бутылку.
  • Бинт — белая бинтовая повязка, предназначенная для лечения двух делений здоровья. Процесс лечения бинтами длится несколько секунд, но с надетой амфой «Эксперт по бинтам» это происходит быстрее.
  • Сильное лекарство — большая бутылка с лекарством, предназначенная для полного лечения здоровья. С надетой амфой «Вторичное использование» после лечения тару из-под лекарства можно использовать, как бутылку.
  • Малая батарея — небольшое устройство, предназначенное для частичной подзарядки прибора ночного видения. С надетой амфой «Замыкание» она частично восстанавливает снаряжение.
  • Большая батарея — большое устройство, предназначенное для полной подзарядки прибора ночного видения. С надетой амфой «Замыкание» она частично восстанавливает снаряжение.
  • Зарядка снаряжения — одноразовое зарядное устройство, предназначенное для мгновенной подзарядки снаряжения.
  • Шприц — медицинский шприц с атропином, предназначенный для оживления мёртвых союзников. С надетой амфой «Двойные дозы» один шприц можно использовать дважды.
  • Оживин — таблетка с атропином, предназначенная для добавления числа возрождений в одиночной игре.
  • Бустер батареи — усиленное устройство, предназначенное для полной подзарядки и увеличении заряжа прибора ночного видения. Находится в единственном экземпляре в секретной комнате на большом испытании. С надетой амфой «Усиление» может случайно оказаться в инвентаре в начале испытания. Также с надетой амфой «Замыкание» он полностью восстанавливает снаряжение.
  • Бустер выносливости — усиленный адреналин, предназначенный для восстановления и длительного повышения выносливости. Находится в единственном экземпляре в секретной комнате на большом испытании. С надетой амфой «Усиление» может случайно оказаться в инвентаре в начале испытания.
  • Бустер здоровья — большая бутылка с усиленным лекарством, предназначенная для полного лечения здоровья и добавления дополнительного деления. Находится в единственном экземпляре в секретной комнате на большом испытании. С надетой амфой «Усиление» может случайно оказаться в инвентаре в начале испытания.
  • Главный ключ — специальный неограниченный ключ, предназначенный для стопроцентного и быстрого отпирания запертых на электронный замок контейнеров и дверей. Находится в единственном экземпляре в секретной комнате на большом испытании.
  • Микроволновый пульт — специальный пульт, предназначенный для активации заряда на головах козлов отпущения. Воздействие на заряд длится несколько секунд (Оправдать виновного, Сбегите из суда, Порадуйте прокурора).
  • Датчик — специальный датчик, предназначенный для выявления местоположения козлов отпущения с помощью загорающихся при приближении к цели пяти индикаторов (Оправдать виновного, Сбегите из суда, Порадуйте прокурора).
  • Сердце — настоящее сердце, предназначенное для метания по мишеням аттракционов и Футтерманов. Также сердцем можно обезвредить вражеские мины и взрывные ловушки (Измельчите негодяев, Просверлить Футтермана, Сломайте Футтерманов).
  • Пакет с наркотиками — маленький пакет с наркотиками, предназначенный для того, что спрятать его в брюшной полости человека или бочке (Отравите лекарство, Спрячьте контрабанду).
  • Дешифратор — специальный пульт, предназначенный для расшифровки нарисованных символов, чтобы получить кодовые цифры от ячеек-головоломок (Отравите лекарство, Опустошите хранилище).
  • Восстановитель здоровья — таблетка, предназначенная для добавления делений здоровья во время вариатора с одной ячейкой здоровья в начале испытания во время Еженедельной терапии или Эскалации.
  • Продлеватель времени — одноразовое устройство во время действия временной программы «Обратный отсчёт», предназначенное для увеличения 1 минуты времени на бомбе (до 5 минут). Независимо от того, кто нашёл и активировал продлеватель, время на бомбах увеличится у всех.

Тяжёлые предметы

  • Канистра с топливом — тяжёлая канистра с бензином, предназначенная для заправки генератора (Убейте стукача, Саботируйте карантин, Причастите сирот, Воссоедините семью, Запитайте отпирающий механизм, Протокол Освобождения).
  • Отбеливатель — тяжёлый бутыль с отбеливателем, предназначенный для выливания в суповую смесь в чане (Накормить детей).
  • Киноплёнка — тяжёлая катушка с фильмом, предназначенная для вставления её в кинопроектор (Причастите сирот, Обучите полицейского, Протокол освобождения).
  • Ведро с кислотой — тяжёлое ведёрко с кислотой, предназначенное для уничтожения человеческих останков. Поскольку ведро открытое, с ним нельзя бегать и прыгать, так как это разбрызгивает кислоту и приносит вред здоровью.
  • Коробка с информацией — тяжёлая открытая коробка с документами, предназначенная либо для уничтожения её в измельчителе, либо же для поставки её на стол (Вводное испытание, Уничтожьте прошлое, Протокол освобождения).
  • Коробка с секс-игрушками — тяжёлая закрытая коробка с секс-игрушками, предназначенная либо для уничтожения её в прессовщике, либо же для изготовления секс-игрушки. Неправильные коробки в руках взрываются (Извратить Футтермана, Раздавите секс-игрушки).
  • Коробка с вещами — тяжёлая открытая коробка с вещами, предназначенная для доставления её в лодку (Опустошите хранилище).
  • Канистра с ядом — тяжёлая канистра с ядом, предназначенная либо для отравления наркотиков, либо для добавления её в отравляющий механизм. Длительное держание канистры в руках приводит к отравлению (Отравите лекарство, Отравите скот).
  • Голова — тяжёлая отсечённая человеческая голова из ячеек-головоломок, предназначенная для кидания её в фонтан для улик (Оправдать виновного).
  • Брикет с наркотиками — тяжёлый брикет наркотиков, предназначенный для поставки его в машину производства наркотиков (Отравите лекарство).
  • Манекен ребёнка — тяжёлый механический манекен в виде ребёнка, предназначенный либо для уничтожения его в измельчителе, либо же для погрузки в машину (Соберите детей божьих, Воссоедините семью, Накажите негодяев).
  • Садистический манекен — тяжёлый механический манекен в виде проститутки, предназначенный для установки на сцене или погрузки в кузов (Порадуйте прокурора, Похитьте любовницу).
